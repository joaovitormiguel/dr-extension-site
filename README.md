# Drayrates for Chrome · landing page prototype

Interactive prototype of the Chrome-extension landing page, by Champion Digital Media for Drayrates.

- **Live:** https://joaovitormiguel.github.io/dr-extension-site/
- **Hero demo:** pick a lane, watch the extension scan the email and lock the market rate, open the quote builder, drag the margin, press Reply.
- **Copy:** follows the Unified Messaging Brief (Sep 2026). Lanes and rates shown are from the Sep 4 demo and the Web Store screenshots, pending verification against the verified-tight list.
- **Motion:** custom ease-out / ease-in-out curves, UI motion under 300ms, reveals that never scale from 0, 50–60ms staggers, `prefers-reduced-motion` respected.

Static HTML, no build step. Open `index.html` or serve the folder.
